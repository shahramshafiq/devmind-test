# devmind-test

## Utilities
The project includes several utility functions for mathematical operations.

- `calculate_factorial(n)`: Calculates the factorial of a given non-negative integer `n`.
  - Parameters: `n` (int) - The input number.
  - Returns: `int` - The factorial of `n`.
  - Raises: `ValueError` if `n` is negative, `TypeError` if `n` is not an integer.
